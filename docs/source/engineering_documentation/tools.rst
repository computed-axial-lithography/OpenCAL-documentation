Tools
======

Below are the tools required for the build of the OpenCAL printer. 
It includes machinery and handheld tools for all phases of the build.

Machinery
----------
* Laser Cutter
    * 1/8'' Acrylic Capable
    * Minimum Bed Size of 18'' x 12''
    * **Laser Cutter used to make original version: Universal Systems Laser-Cutter (32'' x 18'')**
    * Another alternative (if you do not own a laser cutter) is to use an online laser cutting service like 
        https://sendcutsend.com/ or https://www.xometry.com/.
* 3D Printer  
    * PLA, PETG, & TPU Capable
    * Minimum Bed Size of 200 mm x 200 mm
    * **3D Printer used to make original version: Prusa MK4S & Bambu X1 Carbon**

Handheld Tools
--------------
* Metric Hex Key Set
* Metric Allen Wrench Set
* Adjustable Wrench
* Soldering Iron
* Crimping Pliers
* Wire Strippers
* 3/16'' Allen/Hex Key
